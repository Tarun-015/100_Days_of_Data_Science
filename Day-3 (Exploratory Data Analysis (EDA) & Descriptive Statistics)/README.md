Day 03 — Exploratory Data Analysis (EDA) & Descriptive Statistics
100 Days of Data Science | Understanding data before building models.

🎯 Objective
Learn how to explore, summarize, and interpret datasets using descriptive statistics and visualizations.
📚 Topics Covered
1. Central Tendency: Mean, Median, Mode
2. Dispersion: Range, Variance, Standard Deviation, IQR
3. Data Distributions: Histograms, Density Plots, Box Plots
4. Distribution Shape: Skewness and Kurtosis
5. Outlier Detection: IQR Method and Z-Score
6. Position Measures: Percentiles and Quartiles
7. Relationships: Covariance and Correlation
8. Statistical Interpretation: Understanding patterns, limitations, and common mistakes.
📊 Dataset
Titanic Passenger Dataset

Source: Seaborn Titanic Dataset

We'll investigate passenger age, ticket fares, passenger classes, survival rates, and relationships between variables.
🔬 Practical Implementation
Using Python, Pandas, NumPy, Matplotlib, and Seaborn:
- Inspect dataset structure and missing values.
- Calculate descriptive statistics.
- Analyze distributions and identify potential outliers.
- Visualize relationships between variables.
- Interpret statistical findings.
💡 Key Learning Outcomes
- Understand how data is distributed.
- Identify variation and unusual observations.
- Interpret skewness, kurtosis, and correlation.
- Distinguish statistical association from causation.
- Develop the habit of investigating data before modeling.
🎯 Key Takeaway
Don't just calculate statistics. Understand what they reveal about the data.
First understand the data. Then question the data. Only then build something using it.
