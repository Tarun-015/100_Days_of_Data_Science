Today's central question:

How can we train a machine learning model on a small portion of data and trust that it will perform well on data it has never seen?

This is where sampling and train-test splitting come into the picture.

The objective today isn't just to learn train_test_split() from Scikit-learn. It's to understand the statistical reasoning behind it, the assumptions we make, and the mistakes that can make our model evaluation misleading.
